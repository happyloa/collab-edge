# 作品整理交付

更新於 2026-10-10。專案已完成可展示、可維護的履歷作品整理，並補上分批事件保留與跨瀏覽器重點流程。這份文件列出目前成果與驗收邊界；逐批測試、提交與部署證據見 [交付狀態](delivery-status.md)。

## 完成的工作

- 更新相容套件與 Vinext 開發／建置整合，保留有依據的 TypeScript、Vitest 相容版本。修補 braces 的深層解析風險，升級 source-map-js 1.2.2，加入惡意輸入與鎖檔檢查。原生部署現在也會先跑 high audit。
- 改善註冊與登入：帳號和 session 原子提交、保留 API 錯誤狀態、登入過期時可另開分頁恢復、禁止跨帳號重送草稿。完成獨立 session 簽章密鑰與版本化 password pepper 的輪替；登入欄位與登出操作等待初始化。
- 加入有期限與容量限制的本機草稿，按使用者、看板及分頁隔離，支援重新整理後恢復、離線編輯及明確的衝突處理。
- 完成版本化看板匯出、驗證預覽、分批上傳與斷線續傳還原。還原建立獨立看板，授權、關聯、交易與配額均由伺服器檢查；附件二進位與舊事件歷史不包含在備份中。
- 加入擁有者容量檢視與配額錯誤恢復，驗證權限撤銷、擁有權移轉、帳號刪除與競爭時的交易回滾。
- 加入擁有者預覽與確認的事件清理：保留最近 200 次修改，僅清除超過 30 天的內容，每次最多 100 筆。UUID、看板資料與累計配額保留；重試固定原範圍。完成清理後的校驗、還原中斷、DO 驅逐、收據重試與暫存清理演練。[保留規則](event-retention.md)。
- 拆分卡片對話框、活動紀錄、工作區成員管理及帳號刪除元件。改善鍵盤焦點、未存內容提示、手機操作、工作區切換與重複送出保護，保留失敗時的輸入。
- 建立 25／100／200 張卡片、最高 4,000 則留言的可重現瀏覽器效能基準，記錄快照大小與互動結果，改善高留言量比對。這是本機開發環境量測，不能代替正式站或慢裝置驗收。
- 同步操作、架構、測試與作品展示文件，保留分批提交、GitHub CI／CodeQL、公開展示版與 Cloudflare 原生建置的實際證據。

## 驗證與部署

本機完整 verify、88 個 Workers／核心測試、14 個 React UI 測試與 47 個瀏覽器情境通過：Chromium 35 個、Firefox 6 個、WebKit 6 個。後兩者涵蓋登入導航、桌面與手機寬度的鍵盤對話框，以及歷史維護；不代表全功能、實機 Safari 或讀屏驗收。公開展示建置與 2 個獨立情境亦通過。本輪最新的 CI、CodeQL 與原生部署結果集中記錄於[交付狀態](delivery-status.md)。

分批事件維護已透過 GitHub 原生建置部署，migration 套用成功。Access 仍只允許擁有者信箱，正式附件停用；發布前後的查詢顯示建置額度未達上限。本輪沒有新增雲端產品或改動計費方案；Workers Free 依使用者確認，尚未獨立讀取帳單方案。發布版本與 migration 證據見交付紀錄。
